Uses the browser Web Serial API (Chrome / Edge / Opera). Connect to the iCEBreaker's virtual COM port, e.g. /dev/cu.usbserial-* on macOS or /dev/ttyUSB1 on Linux, at 115200 baud. Moving a fader sends the frame EE param value over the onboard FT2232H UART — pin 6 (RX) / pin 9 (TX).
